# Volatility-Arbitrage-under-Discrete-Delta-Hedging

This repository contains the code for the paper 

### "Volatility Arbitrage under Discrete Delta Hedging" by Simon Paul Reuter (SSRN ID: 6778301).

Link to the paper: https://ssrn.com/abstract=6778301

If you use this code, please cite the paper.

## Set up

```bash

    # Create a virtual environment
    python -m venv venv

    or py -m venv venv

    # Activate the virtual environment
    # On Windows:
    venv\Scripts\activate

    # Install the required packages
    pip install -r requirements.txt
```

## Usage

To run the code, simply execute the `script.py` file:

```bash
    python src/script.py 
    or py src/script.py
```
